LoungeOS – Infrastructure Hardening (Pre-Module 3)

Module 2 has been completed successfully and verified.

Do NOT begin Module 3 (Ordering Engine) yet.

Do NOT redesign the mobile UI.

Do NOT change any existing customer or staff screens.

The objective of this phase is to finish the production infrastructure so every future module is built on a stable foundation.

1. Global Audit Logging

Implement a reusable audit logging system.

Create:

AuditService
AuditRepository

Firestore collection:

clubs/{clubId}/auditLogs

Every important action must automatically create an audit record.

Examples:

Session started
Guest joined
Session recovered
Session closed
Order created
Order cancelled
Payment completed
Waiter accepted request
Inventory updated
Business day opened
Business day closed
Configuration changed
DJ request accepted

Each audit record should contain:

actorId
actorType
action
resourceType
resourceId
timestamp
metadata

7. Soft Delete Framework

Support logical deletion using:

deletedAt

deletedReason

Repositories must ignore deleted records by default.

8. Optimistic Locking

Protect Firestore writes using:

version
updatedAt

Reject stale concurrent updates.

13. Performance Monitoring

14. Testing

Create unit tests for every infrastructure service.

Add integration tests where appropriate.
