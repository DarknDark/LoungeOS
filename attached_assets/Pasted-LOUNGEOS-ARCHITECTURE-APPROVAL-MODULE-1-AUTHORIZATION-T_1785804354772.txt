STEP 3 – BEGIN MODULE 1

After documentation is complete, begin only:
Module 1 – Architecture Refactor

The goal of Module 1 is NOT to build features.

Its goal is to build the foundation.

Module 1 should:

    Separate business logic from UI.

    Introduce repository interfaces.

    Introduce service layer.

    Create shared domain models.

    Create Firestore model definitions.

    Separate Customer and Staff applications.

    Remove hardcoded business data.

    Add centralized Settings foundation.

    Add Notification foundation.

    Add Audit foundation.

    Add Analytics foundation.

    Add Activity Feed foundation.

    Establish dependency boundaries.

    Create reusable interfaces for future modules.

Do NOT implement customer ordering, staff dashboards, or M-Pesa yet.
