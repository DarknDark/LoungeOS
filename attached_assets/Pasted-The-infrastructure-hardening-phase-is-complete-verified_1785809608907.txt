Idempotency Keys

Pricing Engine
Centralize all price calculations (subtotal, tax, service charge, discounts, totals) into a reusable service for future payment and split-bill modules.

Emit standardized domain events for every order state transition through the existing event bus so Analytics, Notifications, Kitchen, Inventory, and Smart Waiter Mode can subscribe without modifying Module 3.
